Add baseline unit tests for the four zero-coverage service files (`auditService`, `supportService`, `razorpayService`, `activityService`). Target >30% coverage per service (foundation for future expansion).

**Current State:**
- `auditService.ts`: 0% coverage (supports ADMN requirements, completely untested)
- `supportService.ts`: 0% coverage (support ticket system, completely untested)
- `razorpayService.ts`: 0% coverage (payment provider integration, completely untested)
- `activityService.ts`: 0% coverage (event/activity tracking, completely untested)

**Audit Finding:**
```
All four services: 0% coverage (no tests at all)
Risk: Changes to these services have no detection mechanism
```

- ✅ All tests pass
- ✅ Mock setup is clean and reusable

<task id="10.2.4">
**Write activityService.test.ts — Event tracking**

1. Create test: `src/services/__tests__/activityService.test.ts`
2. Analyze activityService:
   - Likely functions: `logEvent()`, `getActivity()`, `getActivityForUser()`, `filterByEventType()`, etc.
   - User activity tracking (bookings, messages, profile updates, etc.)

3. Test cases:
   ```typescript
   describe('activityService', () => {
     describe('logEvent', () => {
       it('records user activity event', async () => {
         const event = await activityService.logEvent({
           userId: 'user-1',
           eventType: 'booking_created',
           metadata: { bookingId: 'booking-1' },
         });
         expect(event).toHaveProperty('timestamp');
         expect(event.eventType).toBe('booking_created');
       });
       
       it('throws on invalid event type', async () => {
         // Test: only allowed event types accepted
       });
     });
     
     describe('getActivity', () => {
       it('retrieves user activity history', async () => {
         const events = await activityService.getActivityForUser('user-1');
         expect(Array.isArray(events)).toBe(true);
       });
       
       it('filters by event type', async () => {
         const bookingEvents = await activityService.getActivity({
           userId: 'user-1',
           eventType: 'booking_created',
         });
         expect(bookingEvents.every(e => e.eventType === 'booking_created')).toBe(true);
       });
       
       it('returns empty if no activity', async () => {
         const events = await activityService.getActivityForUser('unknown-user');
         expect(events).toEqual([]);
       });
     });
     
     describe('event ordering', () => {
       it('returns events in reverse chronological order', async () => {
         const events = await activityService.getActivityForUser('user-1');
         // Latest event should be first
         expect(events[0].timestamp >= events[1].timestamp).toBe(true);
       });
     });
   });
   ```

4. Test event types: booking_created, message_sent, profile_updated, etc.
