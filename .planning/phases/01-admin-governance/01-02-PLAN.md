## Objective

Ensure verification queue consistently reflects only pending records and that all high-risk admin actions generate fully auditable logs with structured metadata.

**Purpose:** Ensure ADMN-03 (reliable queue visibility) and ADMN-04 (comprehensive auditability) are robust across refresh, filter, and edge cases.

**Output:**
- Verification queue only shows pending-status users
- Queue refreshes on tab switch and after every action
- All high-risk actions (role change, disable, delete) automatically logged with action, actor, target, and details
- Audit logs cannot be modified by users via Firestore rules
